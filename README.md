# Roulette of Hope

A simple Python roulette game made with the PyGame Library.

## Features

- Spin a roulette wheel with animated rotation
- Bet on RED, BLACK, or GREEN (GREEN pays 14x!)
- Adjustable bet amount or go ALL IN
- Background casino music with volume control 
- "Bailout" system — hit $0 and a generous friend gives you $10 to keep going

## Requirements

- Python 3.x
- pygame

## How to Play

1. Select your color bet (RED, BLACK, or GREEN)
2. Enter a bet amount or click ALL IN
3. Hit SPIN and watch the wheel
4. WIN: RED/BLACK pays 2x, GREEN pays 14x
